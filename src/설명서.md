## 1. 개요

**HEC-1 임계지속기간 자동 산정 시스템**은 HEC-1을 이용하여 재현기간·지속기간별 홍수량을 일괄 계산하고, 각 지점의 **임계지속기간**과 **기본홍수량**을 자동으로 산정하는 도구입니다.

### 주요 기능

| 기능 | 설명 |
|------|------|
| 확률강우량 자동 계산 | 관측소별 강우강도식(poly6)으로 재현기간×지속기간별 강우량 산정 |
| 유역별 Huff 시간분포 | 관측소별 군집번호 기반 가중 평균 Huff 3분위 누가분포 |
| ARF 자동 적용 | 유역 면적·권역별 면적우량환산계수 자동 계산 |
| HEC-1 병렬 실행 | CPU 코어 수만큼 동시 해석으로 계산 시간 단축 |
| 결과 자동 집계 | 임계지속기간·기본홍수량 CSV 저장 및 화면 출력 |

### 계산 흐름

```
강우강도식 계산
  → 유역별 Huff 시간분포 (관측소 군집 가중 평균)
    → HEC-1 DAT 파일 생성 (재현기간 × 지속기간)
      → HEC-1.exe 병렬 실행
        → OUT 파일 파싱 (첨두홍수량 추출)
          → 임계지속기간·기본홍수량 산정
            → CSV 저장 + 화면 출력
```

## 5. input.xlsx 시트별 작성 방법

### 📋 기본설정

| 항목명 | 예시 | 설명 |
|--------|------|------|
| `HEC1_EXE` | `C:\HEC1\hec1.exe` | HEC-1 실행 파일 전체 경로 |
| `WORK_DIR` | `C:\HEC1\output` | 계산 결과 기본 저장 폴더 |
| `DT_MIN` | `10` | 계산 시간간격 (분), 지속기간의 약수여야 함 |
| `HUFF_QUARTILE` | `3` | Huff 분위 (환경부 지침: 3분위) |
| `BASIN_AREA_KM2` | `27.0` | 유역 대표면적 (km²) |
| `ARF_REGION` | `한강` | `한강` / `낙동강` / `금강` / `영산강` |
| `PROJECT_NAME` | `Project(Flood)` | 프로젝트명 (결과 하위폴더명으로 사용) |

> 결과 저장 경로: `WORK_DIR\PROJECT_NAME\단위도방법\`

---

### 📋 재현기간 / 지속기간

- **재현기간**: 계산할 재현기간 목록 (년). 예: 2, 10, 20, 30, 50, 80, 100, 200, 500
- **지속기간**: 계산할 지속기간 목록 (분). 예: 60, 70, 80, … , 720
- 지속기간은 반드시 `DT_MIN`(시간간격)의 배수여야 합니다.

---

### 📋 관측소_강우강도식

관측소별 Huff 군집번호와 재현기간별 강우강도식 계수를 입력합니다.

| 열 | 내용 | 예시 |
|----|------|------|
| 관측소명 | HEC-1 PG 카드에 사용 (최대 6자) | `STA` |
| huff_cluster | Huff 군집 번호 (1~26, 기상청 보고서 확인) | `9` |
| 재현기간(년) | 해당 계수의 재현기간 | `100` |
| 식종류 | `poly6` 고정 | `poly6` |
| a0 ~ a6 | poly6 회귀계수 | (보고서 값 입력) |

**poly6 강우강도식:**

```
log(R) = a0 + a1·x + a2·x² + a3·x³ + a4·x⁴ + a5·x⁵ + a6·x⁶
```
> x = log(지속기간(분)), R = 강우량(mm)

**DUMMY 관측소**: 가중치 0으로만 사용되는 더미 관측소. `관측소명` 열에 `DUMMY`라고 입력하면 나머지 열을 비워도 됩니다.

---

### 📋 유역_관측소가중치

각 유역에서 사용하는 관측소별 티센 가중치를 입력합니다.

| 열 | 내용 | 예시 |
|----|------|------|
| 유역명 | 유역네트워크의 유역명과 동일 | `BS050` |
| 관측소명 | 관측소_강우강도식의 관측소명 | `STA` |
| 가중치 | 티센 가중치 (유역별 합계 = 1.0) | `0.60` |

**예시 (BS050 유역):**

| 유역명 | 관측소명 | 가중치 |
|--------|---------|--------|
| BS050 | STA | 0.60 |
| BS050 | STB | 0.40 |
| BS050 | DUMMY | 0.00 |

HEC-1 결과 파일에서 출력할 지점 목록입니다.

|----|------|------|
| 소명 | KK 카드의 지점명 | `BS040` |

### 📋 유역네트워크

계산 요소를 순서대로 나열합니다. `type`에 따라 사용하는 열이 다릅니다.

#### type: `basin` (소유역)

| 열 | 내용 |
|----|------|
| name | 지점명 (최대 6자) |
| area_km2 | 유역 면적 (km²) |
| cn | SCS CN값 |
| method | 단위도 방법: `clark` / `snyder` / `scs` |
| tc | [Clark] 집중시간 tc (hr) / [Snyder] tp (hr) / [SCS] 지체시간 lag (hr) |
| r | [Clark] 저류상수 r / [Snyder] 첨두계수 cp / [SCS] 미사용 |

#### type: `raw_basin` (잔류유역, KKX 형식)

- `basin`과 동일하나 `kk_line` 열에 `KKXBS000` 형식으로 KK 라인 전체를 직접 입력

#### type: `reservoir` (저수지 추적)

- `저수지_저류량` 시트와 `저수지_방류구` 시트에서 데이터를 읽습니다.
- 유역네트워크 시트에는 `name`만 입력하면 됩니다.

#### type: `routing` (하도 추적, Muskingum)

| 열 | 내용 |
|----|------|
| k | 추적 계수 K (hr) |
| x | 가중계수 X (0.0 ~ 0.5) |
| n_reaches | 분할 수 (기본값: 1) |

#### type: `combine` (수문곡선 합성)

| 열 | 내용 |
|----|------|
| n_inputs | 합성할 수문곡선 수 |

#### type: `hydrograph` (외부 수문곡선 직접 입력)

- `외부수문곡선` 시트에서 지점명과 유량 배열을 읽습니다.

---

### 📋 저수지_저류량

표고-저류량 곡선을 입력합니다.

| 열 | 내용 |
|----|------|
| 저수지명 | 유역네트워크의 reservoir 이름과 동일 |
| 표고(m) | 수면 표고 |
| 저류량(천m³) | 해당 표고의 저류량 |

저수지가 여러 개인 경우 저수지명만 다르게 하여 같은 시트에 이어서 입력합니다.

---

### 📋 저수지_방류구 (옵션 1: 방류공식)

여수로 특성을 공식으로 입력합니다. HEC-1 **SS 카드**에 해당합니다.

**방류 공식: Q = C × L × (WSE − E₀)^n**

> Q: 방류량 (m³/s), WSE: 현재 수면 표고 (m)

| 열 | HEC-1 변수 | 내용 | 예시 |
|----|-----------|------|------|
| 저수지명 | — | 유역네트워크의 reservoir 이름 | `RE040` |
| 마루표고(m) | ELST | 여수로 마루 표고 — 이 표고 이상에서 방류 시작 | `93.00` |
| 마루길이(m) | WLEN | 여수로 유효 방류 폭 | `82.00` |
| 유량계수(C) | COEF | 방류 계수 (월류 위어: 약 2.1~2.2) | `2.18` |
| 유량지수(n) | EXPO | 방류 지수 (월류 위어=1.5, 오리피스=0.5) | `1.50` |
| 방류_KK | — | 방류 수문곡선을 저장할 스테이션 번호 | `21` |

---

### 📋 저수지_방류량 (옵션 2: 수위-방류량 테이블)

계산된 수위-방류량 곡선이 있는 경우 테이블로 직접 입력합니다. HEC-1 **SQ 카드**에 해당합니다.

> **옵션 1과 옵션 2는 하나만 사용하세요.** 같은 저수지에 두 시트 모두 입력하면 `저수지_방류량`이 우선 적용됩니다.

| 열 | 내용 | 비고 |
|----|------|------|
| 저수지명 | 유역네트워크의 reservoir 이름 | 행마다 반복 입력 |
| 수위(m) | 저수지 수면 표고 | 오름차순 입력 권장 |
| 방류량(m³/s) | 해당 수위의 방류량 | |
| 방류_KK | 방류 수문곡선 저장 번호 | **첫 번째 행에만 입력** |

**입력 예시 (RE040 저수지):**

| 저수지명 | 수위(m) | 방류량(m³/s) | 방류_KK |
|---------|--------|------------|--------|
| RE040 | 93.00 | 0.00 | 21 |
| RE040 | 93.10 | 5.00 | |
| RE040 | 93.20 | 12.00 | |
| RE040 | 93.30 | 22.00 | |
| RE040 | 93.40 | 36.00 | |
| ... | ... | ... | |

### 저수지 여러 개 입력 방법

모든 저수지 시트(`저수지_저류량`, `저수지_방류구`, `저수지_방류량`)는 저수지명별로 구분하므로, 여러 저수지의 데이터를 같은 시트에 이어서 입력하면 됩니다.

```
RE040  93.10   5  ...
...
RE010  95.00   0  ...  (2번 저수지)

...
```

## 6. 실행 방법

### 기본 실행

```
hec1_auto.exe
```

프로그램이 시작되면 다음 6단계가 순서대로 진행됩니다:

```
[Step 1-2] 확률강우량 + 유역별 Huff 분포 계산
[Step 3]   HEC-1 입력파일 생성
[Step 4]   HEC-1 실행  (병렬)
[Step 5]   출력파일 파싱
[Step 6]   결과 집계
```

### 명령행 옵션

| 옵션 | 설명 |
|------|------|
| `--dry-run` | DAT 파일만 생성, HEC-1 실행 안 함 (입력 확인용) |
| `--parse-only` | 기존 OUT 파일 파싱만 (HEC-1 재실행 없이 결과 재집계) |

명령 프롬프트에서:
```cmd
hec1_auto.exe --dry-run
hec1_auto.exe --parse-only
```

## 8. 유역 네트워크 구성 방법

### 단순 단일 유역

```
[소유역] → (끝)
```

유역네트워크 시트:

| type | name | area_km2 | cn | method | tc | r |
|------|------|----------|----|--------|----|---|
| basin | BS000 | 15.0 | 80.0 | clark | 1.2 | 1.5 |

---

### 저수지가 있는 유역

```
[상류유역] → [저수지] → [하도추적] → [잔류유역] → [합성]
```

유역네트워크 시트 (순서 중요):

| type | name | 비고 |
|------|------|------|
| basin | ABOVE | 저수지 상류 유역 |
| reservoir | RES | 저수지 (KO 카드로 방류 저장) |
| routing | REACH | Muskingum 하도추적 |
| raw_basin | XBELOW | 잔류유역 (kk_line: KKXBELOW) |
| combine | OUTLET | 수문곡선 합성 (n_inputs=2) |

---

### 복잡한 분기 유역

여러 지류가 있는 경우, 각 지류 → 저수지 → 하도추적 → 잔류유역 → 합성을 반복 구성합니다. 네트워크 요소의 **순서**가 HEC-1 계산 순서와 동일합니다.

## 9. 계산 이론

### 강우강도식 (poly6)

확률강우량 R(mm)를 6차 다항식으로 계산합니다:

```
log₁₀(R) = a₀ + a₁·x + a₂·x² + a₃·x³ + a₄·x⁴ + a₅·x⁵ + a₆·x⁶
```

> x = log₁₀(지속기간 분)

### Huff 시간분포 (수정 Huff 4분위법)

유역 내 관측소별 Huff 군집이 다를 경우, 티센 가중치로 가중 평균합니다:

```
누가비(t) = Σ[ weight_i × Huff_cluster_i(t) ]
```

단, DUMMY 관측소(가중치 0)는 계산에서 제외되고 합계가 1.0이 아닌 경우 정규화합니다.

### 면적우량환산계수 (ARF)

한국건설기술연구원 권역별 ARF 계수를 적용합니다:

| 권역 | 유효 재현기간 |
|------|-------------|
| 한강 | 2, 5, 10, 20, 50, 100, 200년 |
| 낙동강, 금강, 영산강 | 한강 계수로 대체 (경고 메시지 출력) |

유역 면적이 25.9 km² 이하인 경우 ARF = 1.0 적용.

### 단위도 방법

| 방법 | HEC-1 카드 | 입력 파라미터 |
|------|-----------|-------------|
| Clark | `UC tc r` | 집중시간 tc (hr), 저류상수 r |
| Snyder | `US tp cp` | 지체시간 tp (hr), 첨두계수 cp |
| SCS | `UH lag` | 지체시간 lag (hr) |

## 10. 자주 묻는 질문

### Q. 실행 후 "설정 검증 실패" 오류가 나옵니다.

가장 흔한 원인:

| 오류 메시지 | 원인 | 해결 방법 |
|------------|------|---------|
| STATIONS에 재현기간 N년 계수가 없습니다 | 관측소_강우강도식 시트에 해당 재현기간 행이 누락됨 | 모든 재현기간 행 추가 |
| station_weights 합계 ≠ 1.0 | 유역_관측소가중치 합계 오류 | 합계가 정확히 1.0인지 확인 |
| 파라미터 ['tc'] 없거나 0 | tc 값이 0 또는 빈칸 | tc 값 입력 |
| huff_cluster가 없습니다 | 관측소_강우강도식 시트 huff_cluster 열이 비어있음 | 군집번호 입력 |

### Q. HEC-1 실행은 됐는데 모두 실패로 나옵니다.

OUT 파일 마지막에 `NORMAL END OF HEC-1`이 없는 경우입니다.

- HEC-1 실행 파일 경로 (`HEC1_EXE`)가 올바른지 확인
- 생성된 DAT 파일을 직접 열어 카드 형식 확인
- `--dry-run` 옵션으로 DAT만 생성 후 HEC-1을 수동 실행해 에러 확인

### Q. 지속기간이 DT_MIN의 배수가 아닌 오류가 납니다.

예) DT_MIN=10인데 지속기간에 75분이 있을 경우:
- 75 ÷ 10 = 7.5 → 배수 아님 → 오류
- 해결: 지속기간 시트에서 10의 배수만 입력 (70, 80, ...)

### Q. 결과 CSV에 특정 지점이 누락됩니다.

- `출력소` 시트에 해당 지점명이 등록되어 있는지 확인
- 유역네트워크의 `name`과 `출력소`의 `소명`이 정확히 일치하는지 확인

### Q. input.xlsx를 수정했는데 반영이 안 됩니다.

- Excel에서 파일을 저장하고 닫은 후 실행하세요.
- 저장 시 xlsx 형식으로 저장되었는지 확인하세요.

### Q. 템플릿을 새로 만들고 싶습니다.

1. 기존 `input.xlsx`를 삭제합니다.
2. `make_template.exe`를 실행합니다.

> ⚠️ 기존 input.xlsx를 삭제하지 않으면 현재 input.xlsx 값이 기준으로 새 템플릿이 생성될 수 있습니다.
