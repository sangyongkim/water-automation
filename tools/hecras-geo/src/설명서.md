# HEC-RAS 횡단면 지형데이터 생성기

측량 횡단 야장(CSV 파일)을 입력받아 HEC-RAS에서 바로 불러올 수 있는 Geometry 파일(.g01)과 프로젝트 파일(.prj)을 자동으로 생성하는 도구입니다.

---

## 특징

- 측량 횡단 야장 CSV → HEC-RAS `.g01` + `.prj` 자동 생성
- **거리형** 측점 (예: 0, 0.1, 0.2 km) 및 **No형** 측점 (예: No.2+40) 모두 지원
- 좌안·우안 Bank Station 자동 인식 및 Levee 자동 설정 (제방고 + 5 m)
- Manning's n 자동 적용 (0.032 고정)
- 구조물(교량 등) 이름을 횡단면 Description 블록에 자동 기재
- HEC-RAS 5.x 포맷 완전 호환 (CP949 인코딩, 한글 하천명 지원)
- Python 설치 없이 실행 가능한 배포판 제공

## 입력 CSV 형식

| 열 순서 | 항목명 | 설명 |
|--------|--------|------|
| 1 | 측점 | 횡단면 위치 (첫 행에만 기재, 이하 공백) |
| 2 | 거리 | 횡단면 내 수평거리 (m) |
| 3 | 표고 | 지반고 (m) |
| 4 | 제방 | `1` = 좌안, `2` = 우안, 공백 = 일반 |
| 5 | 구조물명 | 교량 등 구조물이 있는 경우 기재 (선택) |

**예시 (`fieldbook.csv`):**

```csv
측점명,거리,표고,제방,구조물명
0,0,32.16,,
,34.78,33.24,1,
,61.66,36.15,2,
,100,34.51,,
0.1,0,35.05,,
,32.23,36.31,1,
,60.38,37.22,2,
,100,35.35,,
0.26,0,38.37,,동산교
,32.39,38.5,1,
,65.39,38.5,2,
,100,38.32,,
```

## 사용 방법

### 방법 1: exe 더블클릭 후 명령 프롬프트 실행

```cmd
hecras_geo.exe fieldbook.csv --river 테스트하천 --reach Reach1
```

### 방법 2: 소스 코드 직접 실행 (Python 환경)

```bash
pip install -r requirements.txt
python hecras_geo.py fieldbook.csv --river 테스트하천 --reach Reach1
```

## 전체 옵션

| 옵션 | 설명 | 기본값 |
|------|------|--------|
| `csv` | 입력 횡단 야장 CSV 파일 경로 | (필수) |
| `--river` | 하천명 (River Name) | `하천명` |
| `--reach` | Reach 명 | `Reach1` |
| `--output` | 출력 .g01 파일 경로 | 입력파일명.g01 |
| `--type` | 측점 형식: `distance` 또는 `no` | `distance` |
| `--spacing` | No형 전용: 정측점 간 거리(m) | (--type no 시 필수) |
| `--title` | Geometry 파일 제목 | `HEC-RAS Geometry` |

### 거리형 측점 예시 (0, 0.1, 0.2 km)

```cmd
hecras_geo.exe fieldbook.csv --river 낙동강 --reach Reach1
```

Reach Length 계산: (현재 측점 − 이전 측점) × 1000 m

### No형 측점 예시 (No.1, No.2, No.2+40, No.3)

```cmd
hecras_geo.exe fieldbook.csv --river 낙동강 --reach Reach1 --type no --spacing 50
```

Reach Length 계산:
- 정측점 간: 측점 차 × 정측점 간 거리
- 가측점 간: (측점 차) × 1000 m
- 가→정 경계: 정측점 간 거리 − 가측점 누적 거리

## 출력 파일

실행 후 입력 파일과 같은 폴더에 두 파일이 생성됩니다.

| 파일 | 설명 |
|------|------|
| `fieldbook.g01` | HEC-RAS Geometry 파일 |
| `fieldbook.prj` | HEC-RAS Project 파일 |

### .g01 구조 (횡단면 1개 예시)

```
Type RM Length L Ch R = 1 ,0.26   ,60,60,60
BEGIN DESCRIPTION:
동산교
END DESCRIPTION:
#Sta/Elev= 15
    0.00   38.37   21.31   38.46   32.39   38.50  ...
#Mann= 3 , 0 , 0
    0.00   0.032       0   32.39   0.032       0   65.39   0.032       0
Levee=-1,32.39,43.5,-1,65.39,43.5,,
Bank Sta=32.39,65.39
XS Rating Curve= 0 ,0
Exp/Cntr=0.3,0.1
```

## HEC-RAS에서 파일 열기

1. HEC-RAS 실행
2. `File > Open Project` → 생성된 `fieldbook.prj` 선택
3. `Edit > Geometric Data` → 횡단면 데이터 자동 로드 확인

> **주의**: `.prj`와 `.g01` 파일은 반드시 **같은 폴더**에 있어야 하며, **파일 기본명이 동일**해야 합니다.  
> 예: `fieldbook.prj` ↔ `fieldbook.g01`

---

## 주의사항

- 각 횡단면에 **좌안(1)과 우안(2) Bank Station이 반드시 포함**되어야 합니다.
- 포인트 수가 2개 미만인 횡단면은 자동으로 제외됩니다.
- 거리값이 역전된 경우 경고를 출력하며 계속 처리합니다.
- 입력 CSV 인코딩: UTF-8, UTF-8 BOM, CP949(EUC-KR) 자동 감지.
