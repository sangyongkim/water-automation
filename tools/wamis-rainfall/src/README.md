# WAMIS 시강우 데이터 자동 수집기

WAMIS(수자원관리정보시스템, https://www.wamis.go.kr)의 강우관측소 **시강우 데이터**를 자동으로 수집하여 CSV로 저장하는 도구입니다.

---

## 특징

- 6개월 조회 제한을 자동으로 분할하여 **장기간 데이터 연속 수집**
- **5개 관할기관** 관측소 모두 지원 (K-water / 기상청·환경부·농어촌공사·한수원)
- 관측소 코드만 입력하면 **관할기관 자동 감지**
- **다중 관측소** 동시 수집 지원
- 출력 포맷: `station`, `datetime`, `rainfall_mm` (Long 포맷 시계열 CSV)

---

## 사용 방법

### 방법 1: exe 더블클릭 (대화형 모드)

`wamis_rainfall.exe`를 더블클릭하면 아래와 같이 순서대로 입력을 안내합니다.

```
╔══════════════════════════════════════════════════════╗
║       WAMIS 시강우 데이터 자동 수집기 v1.0          ║
╚══════════════════════════════════════════════════════╝

【대화형 모드】 Enter 키를 누르면 [ ] 안의 기본값을 사용합니다.

  관측소 코드 (여러 개면 쉼표로 구분) [10011100]: 10234010
  시작일 (YYYYMMDD) [20200101]: 20200101
  종료일 (YYYYMMDD) [20260429]: 20201231
  저장 파일명 (.csv) [wamis_rainfall.csv]: output.csv
```

수집이 끝나면 **실행한 폴더**에 CSV 파일이 저장됩니다.

---

### 방법 2: 명령 프롬프트(cmd)에서 실행

```cmd
wamis_rainfall.exe --codes 관측소코드 --start 시작일 --end 종료일 --out 출력파일.csv
```

#### 주요 옵션

| 옵션 | 설명 | 예시 |
|------|------|------|
| `--codes` | 관측소 코드 (1개 이상, 공백 구분) | `--codes 10011100 10234010` |
| `--start` | 시작일 (YYYYMMDD) | `--start 20200101` |
| `--end` | 종료일 (YYYYMMDD, 기본: 오늘) | `--end 20221231` |
| `--out` | 저장 파일명 (기본: wamis_rainfall.csv) | `--out result.csv` |

#### 예시

```cmd
:: 관측소 1개, 2020년 전체
wamis_rainfall.exe --codes 10234010 --start 20200101 --end 20201231

:: 관측소 여러 개, 장기간
wamis_rainfall.exe --codes 10011100 10234010 --start 20150101 --end 20241231 --out multi.csv
```

## 출력 CSV 형식

| 컬럼 | 설명 |
|------|------|
| `station` | 관측소 코드 |
| `datetime` | 관측 일시 (YYYY-MM-DD HH:MM:SS, 1시간 단위) |
| `rainfall_mm` | 시강우량 (mm) |
| `verified_mm` | 검증 강우량 (K-water 관측소만 제공) |
| `original_mm` | 원시 강우량 (K-water 관측소만 제공) |

**예시:**
```
station,datetime,rainfall_mm,verified_mm,original_mm
10234010,2020-08-01 08:00:00,33.0,,
10234010,2020-08-01 09:00:00,42.0,,
```

> 결측치(`NaN`)는 빈 칸으로 저장됩니다.

## 관측소 코드 조회 방법

1. WAMIS 접속: https://www.wamis.go.kr
2. 상단 메뉴 **강우** → **시강우** 선택
3. 지도에서 원하는 관측소 클릭 → 8자리 코드 확인

---

## 관할기관 안내

WAMIS 강우관측소는 5개 기관이 관할하며, 이 도구는 **관측소 코드만 입력하면 기관을 자동으로 감지**합니다.

| 기관 | 비고 |
|------|------|
| 한국수자원공사 (K-water) | 전용 DB (organ=04) |
| 기상청 | 공유 DB |
| 환경부 (홍수통제소) | 공유 DB |
| 한국농어촌공사 | 공유 DB |
| 한국수력원자력 | 공유 DB |

## 주의사항

- **인터넷 연결 필수** (WAMIS 서버에 접속)
- 대량 요청 시 서버 부하 방지를 위해 요청 간 1.5초 대기가 적용됩니다.
- 저장 경로에 **쓰기 권한**이 있어야 합니다 (기본: 실행 파일과 같은 폴더).
- 조회 가능한 최대 기간은 제한 없으나, 장기간 수집 시 시간이 오래 걸릴 수 있습니다.
  - 예: 1개 관측소 × 10년 = 약 3~5분 소요
