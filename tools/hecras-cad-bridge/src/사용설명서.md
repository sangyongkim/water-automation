# HEC-RAS CAD Bridge 사용설명서

HEC-RAS 홍수 해석 결과를 AutoCAD(DXF)와 자동으로 연동하는 도구입니다.  
횡단면 계획 수정 → HEC-RAS 재해석 → 홍수위 확인 작업을 반복할 때 수작업을 최소화합니다.

## 1. 시스템 요구사항

| 항목 | 요구사항 |
|------|----------|
| 운영체제 | Windows 10 / 11 (64-bit) |
| Python | **불필요** (exe에 내장) |
| HEC-RAS | 5.0.6 또는 6.6 (COM 자동화 사용 시) |
| AutoCAD | DXF 파일을 열고 저장할 수 있는 모든 버전 (LT 포함) |
| 인터넷 | 불필요 |

> **주의**: HEC-RAS는 반드시 Windows에 정식 설치되어 있어야 COM 자동화가 동작합니다.  
> HEC-RAS 없이도 동작하지만, Step 3 수동 실행 후 HDF5 파일이 있어야 합니다.

## 2. 설치 방법

### 2-1. 압축 파일 해제

배포된 zip 파일을 원하는 위치에 압축 해제합니다.

```
hecras_launcher.zip  →  C:\프로젝트경로\hecras_launcher\
```

### 2-2. config.py 설정

`hecras_launcher\config.py`를 텍스트 편집기(메모장 등)로 열어 HEC-RAS 설치 경로와 COM ID를 설정합니다.  
이후 프로젝트별 경로 변경은 `hecras_launcher.exe` → 메뉴 `0` (Step 0)으로 할 수 있습니다.

### 2-3. 환경 점검

`hecras_launcher.exe`를 더블클릭하여 실행한 후 메뉴에서 `5`를 입력합니다.

다음 항목이 모두 `[OK]`인지 확인합니다:

- ezdxf 패키지
- win32com 패키지 (pywin32)
- HEC-RAS COM 등록 여부
- config.py 경로 설정

## 3. 폴더 구조

압축 해제 후의 폴더 구조입니다. 실제 HEC-RAS 프로젝트 파일과 DXF 파일은 별도 위치에 있어도 됩니다.

```
hecras_launcher/
├── hecras_launcher.exe   ← ★ 실행 파일 (더블클릭으로 실행)
├── config.py             ← ★ 경로 설정 (HEC-RAS 설치 경로·COM ID만 직접 수정)
├── 사용설명서.md
├── README.md
└── _internal/            ← 내부 라이브러리 (수정·삭제 금지)
```

> 프로젝트별 경로(HEC-RAS 프로젝트, DXF 등)는 메뉴 0 (Step 0)으로 변경합니다.

실제 프로젝트 파일 예시:

```
C:\홍수분석\
├── hec-ras\
│   ├── 프로젝트명.prj
│   ├── 프로젝트명.g01
│   └── 프로젝트명.p01.hdf  (HEC-RAS 계산 후 생성됨)
└── dwg\
    ├── crosssections.dxf         (Step 1이 생성)
    ├── crosssections_panels.json (Step 1이 생성)
    └── wse_results.json          (Step 3이 생성)
```

## 4. config.py 설정

config.py에서 **직접 수정이 필요한 항목**은 HEC-RAS 설치 환경에 관한 것입니다.  
프로젝트별 파일 경로와 프로파일은 **메뉴 0 (Step 0)** 에서 변경합니다.

### [1] HEC-RAS 실행 파일 경로

```python
HECRAS_EXE = r"C:\Program Files (x86)\HEC\HEC-RAS\5.0.6\Ras.exe"
```

Step 3에서 COM 연결 실패 시 대안 모드로 HEC-RAS를 직접 실행합니다. 설치 경로가 다른 경우 수정하세요.

### [2] HEC-RAS COM 클래스 ID

```python
HECRAS_COM_ID = "RAS506.HECRASController"
```

| HEC-RAS 버전 | COM ID |
|-------------|--------|
| 5.0.6 | `RAS506.HECRASController` |
| 5.0.7 | `RAS507.HECRASController` |
| 6.6 | `RAS66.HECRASController` |

> 메뉴 `5` (환경 점검)를 실행하면 현재 컴퓨터에 등록된 COM ID를 자동으로 확인할 수 있습니다.

### [3] AutoCAD 레이어 이름 (기본값 그대로 사용 권장)

```python
LAYER_EXISTING = "현황단면"
LAYER_PLANNED  = "계획단면"
LAYER_FLOOD    = "홍수위"
LAYER_LEVEE    = "제방"
LAYER_TEXT     = "단면표시"
```

AutoCAD에서 이미 사용 중인 레이어명과 충돌할 때만 변경하세요.

2. Step 2  — DXF 계획단면 → HEC-RAS geometry 업데이트

## 6. Step 0 — 프로젝트 설정 (경로·프로파일 변경)

`hecras_launcher.exe` 실행 후 메뉴에서 `0` 입력

config.py를 텍스트 편집기로 열지 않고 자주 바뀌는 설정을 변경합니다.

| 하위 메뉴 | 변경 항목 |
|----------|----------|
| 1 | HEC-RAS 프로젝트 파일(.prj) · Geometry(.g0x) · HDF(.p0x.hdf) |
| 2 | DXF 파일 경로 — PANEL_META, WSE_JSON_FILE 자동 파생 |
| 3 | 홍수위 프로파일 이름 또는 번호 |

**HEC-RAS 파일 자동 탐색**: 프로젝트 파일을 변경하면 같은 폴더에서 geometry와 HDF를 자동으로 찾아 제안합니다.

**DXF 연관 파일 자동 파생**: DXF 경로를 변경하면 `PANEL_META`와 `WSE_JSON_FILE`이 같은 폴더에 자동 설정됩니다.

```
  현재 설정:
  ① HEC-RAS  : C:\홍수분석\hec-ras\NW.prj
  ② DXF 파일 : C:\홍수분석\dwg\crosssections.dxf
  ③ 프로파일 : "200yr" (이름 지정)

  1.  HEC-RAS 파일 경로 변경
  2.  DXF 파일 경로 변경
  3.  홍수위 프로파일 변경
  0.  메인 메뉴로 돌아가기
```

## 7. Step 1 — HEC-RAS → DXF 생성

`hecras_launcher.exe` 실행 후 메뉴에서 `1` 입력

**하는 일**:
- HEC-RAS geometry 파일에서 모든 횡단면 지형을 읽습니다.
- HDF5 결과 파일이 있으면 홍수위선도 함께 그립니다.
- `crosssections.dxf` 와 `crosssections_panels.json` 을 생성합니다.
- 횡단면은 **세로 방향으로 배열**되며, 측점이 낮은 하구 단면이 아래에 위치합니다.

**출력 예시**:
```
Step 1: HEC-RAS → DXF
Geometry 파일 읽는 중: C:\홍수분석\hec-ras\NW.g01
  56개 횡단면 로드 완료
DXF 저장: C:\홍수분석\dwg\crosssections.dxf  (56개 단면)
```

**주의**: 기존 DXF가 있을 경우 덮어쓰기 전에 확인 메시지가 표시됩니다. AutoCAD에서 이미 계획단면을 그렸다면 **'n'을 입력**하고 취소하세요.

---

## 8. Step 2 — AutoCAD → HEC-RAS 업데이트

`hecras_launcher.exe` 실행 후 메뉴에서 `2` 입력

**하는 일**:
- DXF의 `계획단면` 레이어 폴리라인 → HEC-RAS geometry `#Sta/Elev` 교체
- DXF의 `제방` 레이어 마커 위치 → `Bank Sta=` 교체 (1cm 이상 변화 시)
- `Levee=` 스테이션 → `Bank Sta=` 에 맞게 자동 동기화
- `#Mann=` 구역 경계 → `Bank Sta=` 에 맞게 자동 동기화 (Manning's n 값은 유지)
- geometry 파일을 쓰기 전에 `.bak` 백업 자동 생성

---

## 9. Step 3 — HEC-RAS 실행 및 홍수위 추출

`hecras_launcher.exe` 실행 후 메뉴에서 `3` 입력

**하는 일**:
- HEC-RAS COM 인터페이스로 현재 계획(plan)을 자동 실행합니다.
- 지정한 홍수위 프로파일의 WSE를 모든 횡단면에서 추출합니다.
- `wse_results.json`에 저장합니다.
- COM 연결 실패 시 HEC-RAS를 직접 실행하는 대안 모드로 전환됩니다.

**프로파일 목록 출력 예시**:
```
  프로파일 조회 중...
  사용 가능한 프로파일 (4개):
    1. PF 1
    2. 80yr
    3. 100yr
    4. 200yr
  선택된 프로파일: [3] 100yr
```

**홍수위 프로파일 지정 방법**:  
Step 3를 한 번 실행하면 위와 같이 전체 프로파일 목록이 출력됩니다.  
원하는 프로파일 이름 또는 번호를 확인한 후 **메뉴 0 (Step 0) → 3번**으로 설정합니다.  
HEC-RAS에서 직접 확인하려면: Edit → Steady Flow Data → 상단 Profile Names 목록.

**대안 모드 (수동)**: COM 연결이 안 될 때

```
  [대안 모드] HEC-RAS를 직접 실행합니다...
  HEC-RAS가 열렸습니다. 계산을 실행한 후 이 창으로 돌아오세요.
  HEC-RAS 계산이 완료되면 Enter를 누르세요...
```

대안 모드에서는:
1. HEC-RAS 프로그램이 열립니다.
2. HEC-RAS에서 Compute → Steady Flow Analysis → Compute 를 실행합니다.
3. 계산 완료 후 명령 프롬프트 창으로 돌아와 Enter를 누릅니다.

---

## 10. Step 4 — 홍수위 → DXF 갱신

`hecras_launcher.exe` 실행 후 메뉴에서 `4` 입력

**하는 일**:
- `wse_results.json`에서 홍수위를 읽어 DXF의 `홍수위` 레이어를 갱신합니다.
- 홍수위선 가운데에 홍수위 값(EL.xx.xxx)을 표시합니다.
- 각 단면의 제방 여유고(제방고 - 홍수위)를 계산하여 출력합니다.

**출력 예시**:
```
제방 여유고 검토:
  RIVER-1|Reach-1|3.307: WSE=23.412, 제방고=24.100, 여유고=+0.688m  OK
  RIVER-1|Reach-1|2.150: WSE=22.876, 제방고=22.500, 여유고=-0.376m  [부족 0.376m]
```

`[부족]` 단면이 있으면 AutoCAD에서 해당 단면을 수정하고 Step 2부터 반복합니다.

## 11. AutoCAD 작업 규칙

### 계획단면 그리기

1. `crosssections.dxf`를 AutoCAD에서 엽니다.
2. 레이어를 `계획단면`으로 설정합니다.
3. **LWPOLYLINE(경량 폴리라인)** 으로 수정 단면을 그립니다.
   - 단면의 시작점부터 끝점까지 전체 폭을 포함해야 합니다.
   - 끊기지 않는 하나의 폴리라인이어야 합니다.
4. 폴리라인은 해당 단면의 **패널(흰색 현황단면 그림) 영역 안**에 있어야 합니다.
5. **DXF 형식(.dxf)으로 저장**합니다 (AutoCAD 기본 저장은 .dwg이므로 주의).

### 레이어 구성

| 레이어명 | 내용 | 수정 여부 |
|---------|------|---------|
| `현황단면` | HEC-RAS 원래 지형 (흰색) | 수정 불필요 |
| `계획단면` | 사용자가 그리는 수정 단면 (빨강) | **이 레이어에 작성** |
| `홍수위` | 홍수위선 및 홍수위 텍스트 (파랑) | Step 4가 자동 갱신 |
| `제방` | 제방 위치 마커 (초록) | 이동하면 Bank Sta 변경됨 |
| `단면표시` | 단면 번호 텍스트 (노랑) | 수정 불필요 |

### 제방 마커 이동 (선택)

`제방` 레이어의 수직선을 좌우로 이동하면 HEC-RAS의 Bank Station이 변경됩니다.  
Step 2 실행 시 1cm 이상 이동한 경우에만 반영됩니다.

## 12. 수작업 수정 시 주의사항

### AutoCAD DXF를 직접 수정할 때

| 작업 | 영향 |
|------|------|
| `현황단면`, `홍수위`, `단면표시` 편집 | 안전 — Step 2가 읽지 않음 |
| `계획단면` 폴리라인 추가/수정 | 정상 동작 |
| `제방` 마커 이동 | 정상 동작 |
| 폴리라인을 패널 경계 **밖**에 그림 | 경고 표시 후 가장 가까운 단면에 적용됨 |
| **Step 1 재실행** | ★ **경고**: `계획단면` 폴리라인이 모두 삭제됨 |

> **Step 1을 재실행해야 하는 경우**: HEC-RAS geometry 파일을 크게 수정했거나(단면 추가/삭제, River/Reach 이름 변경), 처음부터 다시 시작할 때만 Step 1을 재실행하세요.

### HEC-RAS geometry 파일을 직접 수정할 때

| 수정 항목 | Step 2 실행 결과 |
|----------|----------------|
| `#Sta/Elev` (단면 좌표) | DXF에 `계획단면`이 없으면 유지됨. 있으면 DXF 값으로 덮어씌워짐 |
| Manning's n 값 (`.032` 등) | 안전 — 값 자체는 변경하지 않음 |
| `Bank Sta=` | DXF 제방 마커와 다르면 **DXF 값으로 복원됨** |
| Manning's n 구역 경계 스테이션 | Step 2 실행 시 Bank Sta와 일치하도록 자동 수정됨 |
| `Levee=` 스테이션 | Step 2 실행 시 Bank Sta와 일치하도록 자동 수정됨 |

## 13. 오류 해결

### COM 오류: "잘못된 클래스 문자열" 또는 "COM ID를 찾지 못했습니다"

```
원인: config.py의 HECRAS_COM_ID가 현재 PC에 설치된 버전과 다름
해결:
  1. hecras_launcher.exe 실행 후 메뉴 5 (환경 점검) 선택
  2. "[OK] 등록됨: RAS5xx.HECRASController" 항목 확인
  3. 해당 ID를 config.py의 HECRAS_COM_ID에 복사
```

### HDF5 결과 파일 없음 오류

```
원인: HEC-RAS 계산을 아직 실행하지 않았거나 경로가 다름
해결:
  1. HEC-RAS에서 Compute → Steady Flow Analysis → Compute 실행
  2. 메뉴 0 (Step 0) → 1번에서 HDF 파일 경로 확인
     (Plan 번호에 따라 .p02.hdf일 수도 있음)
```

### 계획단면 인식 불가 (Step 2에서 "0개 계획단면 감지")

```
원인 1: AutoCAD 레이어 이름이 다름
  → config.py의 LAYER_PLANNED 값과 AutoCAD 레이어명이 정확히 일치하는지 확인

원인 2: DXF 형식으로 저장하지 않음
  → AutoCAD에서 "다른 이름으로 저장" → 파일 형식: "AutoCAD 2010 DXF (*.dxf)" 선택

원인 3: LWPOLYLINE이 아닌 엔티티 사용
  → AutoCAD에서 PLINE 명령어로 그렸는지 확인 (LINE이 아닌 PLINE/LWPOLYLINE)
```

### Manning's n "not set" 오류 (HEC-RAS 계산 실패)

```
원인: Bank Sta가 변경됐지만 Manning's n 구역 경계가 동기화되지 않음
해결: Step 2를 다시 실행하면 자동으로 동기화됩니다.
```

### DXF 파일 쓰기 실패 (Step 4)

```
원인: AutoCAD가 해당 DXF 파일을 열고 있어 파일 잠금 발생
해결: AutoCAD에서 파일을 닫은 후 Step 4 재실행
```

### [오류] config.py 파일이 없습니다

```
원인: hecras_launcher.exe와 같은 폴더에 config.py가 없음
해결: 배포 패키지의 config.py를 exe와 같은 폴더에 복사하고 경로 설정 후 재실행
```

## 14. 자주 묻는 질문

**Q. 프로젝트 파일 경로를 바꾸려면 어떻게 하나요?**  
A. `hecras_launcher.exe` 실행 후 메뉴 `0` (Step 0) → `1번`을 선택합니다. HEC-RAS 프로젝트 파일(.prj)을 입력하면 geometry와 HDF 파일을 자동으로 탐색해 제안합니다.

**Q. 홍수위 프로파일 이름은 어떻게 확인하나요?**  
A. Step 3 (메뉴 3)를 한 번 실행하면 "사용 가능한 프로파일" 목록이 출력됩니다. 원하는 이름을 확인한 후 Step 0 (메뉴 0) → 3번에서 설정합니다. HEC-RAS에서 직접 확인하려면: Edit → Steady Flow Data → 상단 Profile Names 목록.

**Q. Step 1을 언제 다시 실행해야 하나요?**  
A. HEC-RAS에서 단면을 추가하거나 삭제했을 때, 또는 River/Reach 이름을 변경했을 때입니다. 계획단면 수정 → 반복 작업 중에는 Step 1을 재실행하지 않습니다.

**Q. AutoCAD 없이 사용할 수 있나요?**  
A. DXF 파일을 다른 CAD 프로그램(BricsCAD, ZWCAD 등)이나 FreeCAD로 편집해도 됩니다. LWPOLYLINE을 지원하고 DXF 형식으로 저장할 수 있으면 됩니다.

**Q. HEC-RAS 6.x에서도 동작하나요?**  
A. 네. config.py에서 `HECRAS_COM_ID = "RAS66.HECRASController"`로 변경하고 `HECRAS_EXE` 경로를 6.6 경로로 수정하면 됩니다.

**Q. geometry 파일 백업은 어디에 있나요?**  
A. Step 2 실행 시 geometry 파일과 같은 폴더에 `.bak` 확장자로 자동 저장됩니다 (예: `NW.g01.bak`).

**Q. exe를 이동하거나 다른 PC에서 사용해도 되나요?**  
A. 네. `hecras_launcher.exe`와 `_internal` 폴더, `config.py`를 함께 이동하면 됩니다. Python을 별도로 설치할 필요가 없습니다.
